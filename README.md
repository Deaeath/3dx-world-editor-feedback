# 3DX World Editor: feedback

Bug reports, ideas and incidents for the [3DX World Editor](https://deaeath.github.io/3dx-world-editor/) by KingColossus.

The quickest way to report something is the **Feedback** button inside the editor: it fills in your editor version, browser and any recent errors for you. You can also [open an issue](../../issues/new/choose) here directly.

Please don't attach `.world` files you don't want public: everything in this repository is visible to everyone.
